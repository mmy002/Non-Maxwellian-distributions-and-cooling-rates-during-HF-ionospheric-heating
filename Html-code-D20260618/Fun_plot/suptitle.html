suptitle

PURPOSE

SUPTITLE Puts a title above all subplots.

SYNOPSIS

function hout=suptitle(str,fig)

DESCRIPTION 

SUPTITLE Puts a title above all subplots.
    SUPTITLE('text') adds text to the top of the figure
    above all subplots (a "super title"). Use this function
    after all subplot commands.
