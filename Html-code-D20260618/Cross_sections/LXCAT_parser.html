LXCAT_parser

PURPOSE

LXCAT_parser - parses LXCAT cross-section files, returns structs

SYNOPSIS

function XS_struct = LXCAT_parser(fname)

DESCRIPTION 

 LXCAT_parser - parses LXCAT cross-section files, returns structs
 in cell-array. The structs contain fields:
  type   - the type of collision: 'elastic', 'rotation', 'vibration',
           'excitation', 'ionization'.
  header - cell array with the sub-header as strings, one line per element
  Species - char-array with spieces identifier: O, O2, N2 etc.
  Process - char array describing what collision it is.
  E      - energy, (eV), double array
  xs     - cross-section (m^2), double array with cross-section
 for elastic collisions there is a field:
  m_over_m for the mass-ratio between colliding particle and target
 for other collisions there are fields:
  dE     - excitation-energy (eV) double scalar. Energy cost from the
           lower to the upper state.
  g_over_g - ratio of statistical weights, double scalar.
  
  % Example:
  XS_O2ion = LXCAT_parser('Cross-section-O2-ionization.txt');
  figure
  colormap(turbo)
  for i1 = 1:numel(XS_O2ion)
    dE_O2i(i1) = XS_O2ion{i1}.dE;
  end
  for i1 = 1:numel(XS_O2ion)
    phO2i(i1) = loglog(XS_O2ion{i1}.E,XS_O2ion{i1}.xs);
    hold on
  end
  [~,idE] = sort(dE_O2i);
  cmlines(phO2i(idE))
  lgh = legend(phO2i,num2str(dE_O2i(:)),'location','southeast');
  set(phO2i,'linewidth',2)
  title(lgh,'ionization dE (eV)')
  axis([10 1e3 4e-24 4e-20])
  xlabel('Energy (eV)')
  ylabel('Cross-section (m^2)')
  title('Ionization-cross-sections O_2')
